Problem Formulation & State Space Fundamentals

The 8-Puzzle Problem is a classical state-space search problem consisting of a $3 \times 3$ grid containing 8 numbered square tiles ($1$ to $8$) and a single empty position (blank, denoted by _ or $0$). The objective is to transition from an initial state configuration to a predefined goal state by sliding tiles horizontally or vertically into the empty space.

The complete state space consists of $9! = 362,880$ permutations, divided into two disjoint state spaces of $181,440$ states each based on permutation parity. A problem instance is mathematically solvable if and only if the parity of inversions in the initial state equals that of the goal state: Inversions(Initial) ≡ Inversions(Goal) &pmod{2}.

1. Breadth First Search (BFS)

Allotted Algorithm for Registration No: 24BDS0004
Uninformed Search

Description: Breadth First Search (BFS) explores the state space level by level, systematically examining all nodes at depth $d$ before any nodes at depth $d+1$ are expanded. It uses a First-In, First-Out (FIFO) queue for the frontier (open list).

Working Principle: The initial state node is placed in the queue. In each iteration, the shallowest node is dequeued, checked against the goal state, and added to the explored set (closed list). All valid successors generated by sliding the blank tile are enqueued if not previously visited.

Advantages: Guarantees finding the shallowest goal state. For unit transition costs ($c=1$), it is strictly optimal.

Limitations: Memory requirement grows exponentially with depth, making BFS vulnerable to memory exhaustion for complex puzzle configurations.

Time Complexity: O(bd)
Space Complexity: O(bd)
Completeness: Complete (if b is finite)
Optimality: Optimal (for unit step costs)

2. Depth First Search (DFS)

Uninformed Search

Description: DFS expands the deepest unexpanded node in the current frontier using a Last-In, First-Out (LIFO) stack.

Working Principle: It plunges along a single branch until reaching a state with no successors or a cycle, then backtracks to the most recent ancestor with unexplored branches.

Advantages: Very modest memory consumption ($O(b \cdot m)$).

Limitations: Can wander into infinitely deep paths or loops in graph spaces without cycle detection; solutions found are frequently non-optimal.

Time Complexity: O(bm)
Space Complexity: O(b • m)
Completeness: Incomplete (in infinite state spaces)
Optimality: Non-Optimal

3. Depth Limited Search (DLS)

Uninformed Search

Description: A variation of DFS that restricts exploration to a predetermined depth limit $L$.

Working Principle: Nodes at depth $L$ are treated as if they possess no successors. A cutoff flag is signaled if the goal is deeper than $L$.

Advantages: Solves the infinite path issue inherent in unbounded DFS while retaining linear memory complexity.

Limitations: Incomplete if $L < d$ (shallowest goal depth). Non-optimal if $L > d$.

Time Complexity: O(bL)
Space Complexity: O(b • L)
Completeness: Incomplete if L < d
Optimality: Non-Optimal

4. Iterative Deepening Search (IDDLS)

Uninformed Search

Description: IDDLS combines the space efficiency of DFS with the completeness and optimality guarantees of BFS by incrementally increasing the depth limit: $L = 0, 1, 2, \dots$ until the goal is discovered.

Working Principle: Runs DLS with limit $0$, then limit $1$, etc. While top levels are re-expanded, the overhead is modest because the bottom level dominates the exponential node count.

Advantages: Optimal and complete like BFS, with the linear memory requirement of DFS ($O(b \cdot d)$).

Limitations: Repeated generation of states at shallow levels.

Time Complexity: O(bd)
Space Complexity: O(b • d)
Completeness: Complete
Optimality: Optimal (for unit step costs)

5. Greedy Best First Search (GBFS)

Informed (Heuristic) Search

Description: GBFS uses heuristic information $h(n)$ to expand the node that appears closest to the goal: $f(n) = h(n)$.

Working Principle: Maintains a priority queue sorted exclusively by heuristic estimate $h(n)$ (e.g. Manhattan distance). It disregards accumulated path cost $g(n)$.

Advantages: Often reaches a solution very quickly in practice with few node expansions.

Limitations: Susceptible to misleading heuristic gradients; neither guaranteed complete nor optimal.

Time Complexity: O(bm) worst case
Space Complexity: O(bm)
Completeness: Incomplete in graphs with cycles
Optimality: Non-Optimal

6. A* Search

Informed (Heuristic) Search

Description: A* evaluates nodes by combining cost to reach the node $g(n)$ and estimated cost to goal $h(n)$: f(n) = g(n) + h(n).

Working Principle: Expanding nodes in increasing order of $f(n)$. If $h(n)$ is admissible ($h(n) \le h^*(n)$) and consistent ($h(n) \le c(n, a, n') + h(n')$), A* is guaranteed to discover the optimal path.

Advantages: Optimally efficient: no other optimal search algorithm expands fewer nodes given the same heuristic information.

Limitations: Keeps all generated nodes in memory ($O(b^d)$).

Time Complexity: O(bd)
Space Complexity: O(bd)
Completeness: Complete
Optimality: Optimal (Admissible h)
