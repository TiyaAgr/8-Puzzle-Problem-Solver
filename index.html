Introduction to the 8-Puzzle Problem

State-Space Search Problem

The 8-Puzzle Problem is a classic benchmark in Artificial Intelligence for studying heuristic and state-space search strategies. It consists of a $3 \times 3$ grid with 8 numbered square tiles ($1$ through $8$) and a single empty slot (the blank tile, represented as _ or $0$).

➤
Objective & Goal: Transform an arbitrary Initial State configuration into a predefined Goal State by sliding adjacent tiles horizontally or vertically into the blank slot.
➤
State Space Permutations: The $3 \times 3$ board produces $9! = 362,880$ total possible configurations. However, exactly half ($181,440$) are reachable from any given configuration due to the mathematical invariance of permutation inversions.
➤
Mathematical Solvability Criterion: An initial state can reach the goal state if and only if both permutations possess the identical inversion parity:
Inversions(Initial) ≡ Inversions(Goal) (mod 2)
➤
AI Search Formulations: Explored via Uninformed Search (BFS, DFS, DLS, IDDLS) where no domain knowledge is used, and Informed Search (GBFS, A*) using heuristic approximations such as Manhattan Distance and Misplaced Tiles.

05. 8. Algorithm Information Page

Theoretical Specifications

1. Breadth First Search (BFS)

★ Assigned to Tiya Agrawal (24BDS0004)
Uninformed Search

Description: Systematic level-order search utilizing a First-In, First-Out (FIFO) queue for the frontier list.

Working Principle: Initial state is enqueued. At each step, the shallowest node is dequeued, checked against the goal, and its successors are appended to the queue if not previously seen.

Advantages: Guaranteed to discover the shortest path in terms of steps. Strictly optimal for unit cost transitions ($c = 1$).

Limitations: High exponential memory consumption ($\mathcal{O}(b^d)$) as all generated nodes must be retained in memory.

Time Complexity: O(bd)
Space Complexity: O(bd)
Completeness: Complete
Optimality: Optimal (c = 1)

2. Depth First Search (DFS)

Uninformed Search

Description: Explores the deepest unexpanded node using a Last-In, First-Out (LIFO) stack before backtracking.

Working Principle: Plunges along each branch until a dead end or cycle occurs. Implements cycle checking to prevent infinite loops.

Advantages: Modest linear memory requirement ($\mathcal{O}(bm)$).

Limitations: Not complete in infinite state spaces; solutions found are frequently heavily sub-optimal.

Time Complexity: O(bm)
Space Complexity: O(b • m)
Completeness: Incomplete (infinite paths)
Optimality: Non-Optimal

3. Depth Limited Search (DLS)

Uninformed Search

Description: A modified DFS that caps search traversal at a predetermined depth ceiling $L$.

Working Principle: Branches at depth $L$ are treated as terminal leaf nodes. Signals a cutoff flag if the goal resides deeper than $L$.

Advantages: Solves the infinite path dilemma while maintaining linear memory efficiency.

Limitations: Incomplete if $L < d$; non-optimal if $L > d$.

Time Complexity: O(bL)
Space Complexity: O(b • L)
Completeness: Incomplete if L < d
Optimality: Non-Optimal

4. Iterative Deepening Search (IDDLS)

Uninformed Search

Description: Incrementally increases the depth limit $L = 0, 1, 2, \dots$ until the target state is discovered.

Working Principle: Reaps the linear memory benefits of DFS alongside the completeness and optimality guarantees of BFS.

Advantages: Optimal and complete with minimal space requirement $\mathcal{O}(bd)$.

Limitations: Re-generates nodes at shallow levels across subsequent iterations.

Time Complexity: O(bd)
Space Complexity: O(b • d)
Completeness: Complete
Optimality: Optimal (c = 1)

5. Greedy Best First Search (GBFS)

Informed Search

Description: Expands the frontier node with the minimum heuristic evaluation: $f(n) = h(n)$.

Working Principle: Priority queue ordered strictly by estimated distance to goal, ignoring accumulated path cost $g(n)$.

Advantages: Often discovers solutions very rapidly in low-complexity spaces with minimal expansions.

Limitations: Easily misled by false heuristic gradients; neither complete in cyclic graphs nor optimal.

Time Complexity: O(bm) worst case
Space Complexity: O(bm)
Completeness: Incomplete in graphs
Optimality: Non-Optimal

6. A* Search

Informed Search

Description: Evaluates nodes by combining actual step cost $g(n)$ and estimated cost $h(n)$: f(n) = g(n) + h(n).

Working Principle: Min-priority queue ordered by $f(n)$. If heuristic $h(n)$ is admissible and consistent, A* is provably optimal.

Advantages: Optimally efficient among all search algorithms using the same heuristic.

Limitations: Retains all generated nodes in memory ($\mathcal{O}(b^d)$).

Time Complexity: O(bd)
Space Complexity: O(bd)
Completeness: Complete
Optimality: Optimal (Admissible h)
