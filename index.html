Problem Formulation & Mathematical Solvability Parity

The 8-Puzzle is modeled as a formal state-space search problem over a $3 \times 3$ grid containing 8 numbered tiles and a single blank tile ($0$ or _). The total state space contains $9! = 362,880$ permutations partitioned into two mutually unreachable components of $181,440$ states each.

An initial state is solvable if and only if its inversion count has the identical parity to that of the goal state: Inversions(Initial) ≡ Inversions(Goal) &pmod{2}. This application automatically calculates permutation parity to reject unsolvable inputs and safeguard search execution.

04. Theoretical Foundations & Algorithmic Analysis

Formal AI Reference

1. Breadth First Search (BFS)

★ Assigned to Tiya Agrawal (24BDS0004)
Uninformed Search

Description: Explores state space level by level using a strict FIFO queue. Explores all nodes at depth $d$ before any node at depth $d+1$.

Working Principle: Initial state enqueued into frontier. At each iteration, the shallowest node is dequeued, goal-checked, and expanded. Successors are enqueued if not previously generated or explored.

Advantages: Guaranteed to discover the shortest path in terms of steps. Strictly optimal for unit action costs.

Limitations: High space complexity ($\mathcal{O}(b^d)$) makes BFS memory-prohibitive for deep solutions.

Time Complexity: O(bd)
Space Complexity: O(bd)
Completeness: Complete
Optimality: Optimal (c = 1)

2. Depth First Search (DFS)

Uninformed Search

Description: Traverses deeply along each branch using a LIFO stack before backtracking.

Working Principle: Expands the deepest unexpanded node in the current frontier. Employs cycle-checking to avoid infinite state loops.

Advantages: Modest linear memory requirement ($\mathcal{O}(bm)$).

Limitations: Not complete in infinite state spaces; solutions found are often highly sub-optimal.

Time Complexity: O(bm)
Space Complexity: O(b • m)
Completeness: Incomplete (infinite paths)
Optimality: Non-Optimal

3. Depth Limited Search (DLS)

Uninformed Search

Description: A variant of DFS that imposes a fixed maximum traversal depth limit $L$.

Working Principle: Truncates branches at depth $L$, flagging cutoff conditions if the target state exists at depth $d > L$.

Advantages: Eliminates the infinite path vulnerability of unbounded DFS while preserving linear memory efficiency.

Limitations: Incomplete if $L < d$; non-optimal if $L > d$.

Time Complexity: O(bL)
Space Complexity: O(b • L)
Completeness: Incomplete if L < d
Optimality: Non-Optimal

4. Iterative Deepening Search (IDDLS)

Uninformed Search

Description: Incrementally increases depth limit $L = 0, 1, 2, \dots$ until the goal state is located.

Working Principle: Couples the memory advantages of DFS with the completeness and optimality guarantees of BFS.

Advantages: Optimal and complete with minimal linear space $\mathcal{O}(bd)$.

Limitations: States in shallow levels are regenerated multiple times across deepening iterations.

Time Complexity: O(bd)
Space Complexity: O(b • d)
Completeness: Complete
Optimality: Optimal (c = 1)

5. Greedy Best First Search (GBFS)

Informed Search

Description: Selects the frontier node with the lowest heuristic value: $f(n) = h(n)$.

Working Principle: Employs a priority queue ordered strictly by estimated distance to goal, ignoring step cost $g(n)$.

Advantages: Often discovers solutions rapidly in low-complexity regions with minimal node expansions.

Limitations: Easily deceived by local minima; neither complete in graph search with cycles nor optimal.

Time Complexity: O(bm) worst case
Space Complexity: O(bm)
Completeness: Incomplete in graphs
Optimality: Non-Optimal

6. A* Search

Informed Search

Description: Evaluates nodes by combining step cost $g(n)$ and estimated cost $h(n)$: f(n) = g(n) + h(n).

Working Principle: Priority queue ordered by $f(n)$. If heuristic $h(n)$ is admissible and consistent, A* is guaranteed optimal.

Advantages: Optimally efficient among all search algorithms using the same heuristic.

Limitations: Retains all generated nodes in memory ($\mathcal{O}(b^d)$).

Time Complexity: O(bd)
Space Complexity: O(bd)
Completeness: Complete
Optimality: Optimal (Admissible h)
